01 / Experience

Platform ownership. Measurable impact.

Backend engineering, application security, and production reliability for business-critical financial products.

Own all features and full lifecycle maintenance for a client-facing application, and contribute across three business-critical financial applications—from requirements and design through delivery, monitoring, and production support.

  • Build Java and Spring Boot services and REST APIs for high-volume workflows using microservices, Kafka, MQ, Oracle, and DB2. Improved API latency by about 60% through query and indexing work on 5–6 million row tables, transaction-scale tuning, pagination, and caching.
  • Designed and built the Angular UI application from configuration and implementation through styling and deployment. Browser caching and gzip compression reduced network transfer by 63% on first load, 86% on changed deployments, and 99.9% when there were no changes.
  • Migrated three applications from Apache Nomad containers to Kubernetes, improving deployment speed and making services easier to scale.
  • Remediated 400+ security vulnerabilities, moving critical findings to non-critical levels. Implemented RBAC and entitlements, JWT/JWKS authentication, CORS restrictions, and proxy controls.
  • Improved reliability through rate limiting, backend caching, cache eviction policies, and active monitoring with Grafana, AppDynamics, and Splunk.
  • Built a RAG workflow automation platform using retrieval, prompt engineering, reranking, LLM reasoning, and evaluation, reducing manual operational effort by about 80%. Also created specialized Claude skills to improve engineering workflow efficiency.
  • Built UI and backend automated test frameworks, reaching about 85% coverage across critical workflows; review pull requests, contribute to design discussions, and mentor junior analysts.

  • Built a React, Node.js, and MySQL analytics platform to replace Excel workflows, reducing manual processing time by about 50%.
  • Integrated Azure Synapse and developed an ML anomaly-detection prototype that improved prediction accuracy by 25%.
